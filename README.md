# Rearranged

Built copy; code lives elsewhere.

Rearrange a song in the style of another, in the browser:
https://swwallowws.github.io/rearranged-web/

This repository holds only the built site. The engine runs in your browser
(WebAssembly), MIDI files you open stay there, and it plays through a built-in
General MIDI soundfont. The guided demo is at /try/.
